# AirType AI ✨

> A touchless AI-powered virtual keyboard built using **OpenCV** and **MediaPipe**.

## 📖 About

AirType AI is an AI/Computer Vision project that enables users to type using hand gestures without touching a physical keyboard.

This repository documents the **complete engineering journey**, including project setup, implementation, debugging, design decisions, and daily progress.
